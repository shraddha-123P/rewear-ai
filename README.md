# ReWear AI

A frontend prototype for the 1M1B AI for Sustainability Virtual Internship. ReWear AI helps urban residents choose a responsible next step for unwanted clothes, footwear, undergarments and textiles.

## Run locally

Open `index.html` in a browser. No backend or API is required for this prototype.

## IBM BOB integration

IBM BOB is used for ideation, prompt design, test-case generation and responsible AI review. The system prompt shown in the app documents the intended conversational workflow. For the internship submission, add screenshots from an actual IBM BOB conversation and link them in the Google Form.

## Prototype workflow

1. User describes item type, condition, city and pickup/drop-off preference.
2. The assistant classifies the item and chooses a route: donate, repair, reuse, upcycle, recycle or responsible disposal.
3. The recommendation explains its reasoning and reminds the user to verify current partner rules.

## Portfolio note

This is an intentionally transparent MVP. It uses local matching data so it can run without exposing keys in a frontend app. A production version could add a verified backend database, live partner updates, maps, multilingual support and a secure AI API.
